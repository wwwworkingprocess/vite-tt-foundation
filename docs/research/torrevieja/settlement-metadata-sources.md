# Torrevieja Settlement Metadata — Source / Provenance Register

Access date for the web research: **2026-10-04**. Source IDs are stable within `torrevieja-settlement-metadata.v0.json` and are cited as `[SRC-…]` in the urban report.

Reliability convention: official/planning sources are preferred for names, planning status, land-use and explicit development parameters; open-map/base-map sources are used to cross-check names, topology and POI position; aerial/satellite-derived observations are used only for morphology inference and are never promoted to legal facts. No satellite/aerial image is reproduced in these deliverables.
